# Organizador de Declaração de Imposto de Renda

Esta planilha se destina a ajudar as pessoas a organizar e reunir informações  essenciais para a declaração de imposto de renda.
Nela é possível gerenciar as principiais informações necessárias para fazer a declaração ou enviá-las para um profissional providenciar a confecção e entrega desta a Receita Federal.
Nesta planilha é possível agregar as informações necessárias à declaração como dados:
1.	Pessoais;
2.	Bancários;
3.	Entradas; e
4.	Saídas - planilha voltada a despesas dedutíveis no imposto de renda.
 A planilha foi pensada para facilitar a agregação das informações durante o ano.

Navegação:

Pode-se navegar entre várias as planilhas adicionando as Entradas e Saídas mensalmente, por meio de links.
